# Mais — Xamarin.Forms

> Aplicativo móvel desenvolvido com Xamarin.Forms, com projetos compartilhados e alvos para Android e iOS.

## Organização

- `Droid/` — projeto da plataforma Android.
- `Mais/` — projeto compartilhado da aplicação.
- `UITests/` — testes de interface da aplicação.
- `iOS/` — projeto da plataforma iOS.

Solução: [`Mais.sln`](Mais.sln).

## Tecnologias

C#, Xamarin.Forms e projetos para Android e iOS.

## Como abrir

Abra [`Mais.sln`](Mais.sln) no ambiente de desenvolvimento compatível com a stack do projeto.
